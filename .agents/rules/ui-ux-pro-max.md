## UI/UX Pro Max

When designing, building, reviewing, or fixing UI/UX, interfaces, pages, components, design systems, accessibility, typography, color palettes, or interactions, use the `ui-ux-pro-max` skill.

Rules:
- Access dataset via `.agents/skills/ui-ux-pro-max/scripts/search.py` or `.agents/skills/ui-ux-pro-max/data/` for design intelligence (styles, product palettes, font pairings, UX guidelines, animations, charts).
- Ensure interfaces follow modern aesthetics, responsive layouts, clear visual hierarchy, and accessibility standards.
