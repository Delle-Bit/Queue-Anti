# Gemini / Antigravity instructions

The instructions for every AI assistant on this project live in one place so
they cannot drift apart:

- **[AGENTS.md](AGENTS.md)** — skills, graphify, and the rules that apply to any
  assistant. Read it as if it were this file.
- **[HANDOVER.md](HANDOVER.md)** — run, test, deploy, configuration, known gaps.
- **[CLAUDE.md](CLAUDE.md)** — architecture and the reasoning behind it.

This file used to hold its own copy of AGENTS.md and had already drifted from it
by two paragraphs, which is exactly the failure the rest of this project keeps
designing away from: two copies of one thing that disagree.
